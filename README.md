# QQ空间

让角色经营自己的 QQ空间：接收你引用的照片、按日程分享自拍、回复你的留言，并把这些经历记进 LivingMemory。

插件标识：`astrbot_plugin_qzone_life` · 当前版本：`v0.2.2` · [GitHub 仓库](https://github.com/chouoi344/astrbot_plugin_qzone_life)

## 开始使用

1. 让机器人在 QQ 中正常聊天，在 AstrBot 中把自己的 QQ 设为管理员，并选好角色。
2. 准备好下面三个插件：LivingMemory 能保存记忆，Life Scheduler 能提供日程，Gitee AI Image 能按角色参考照生成自拍。QQ空间会沿用它们已有的设置。
3. 安装 QQ空间，在与角色的 **QQ 私聊** 中说：“以后用现在的角色经营你的空间吧。”
4. 想看准备情况时，直接问：“你的空间现在准备好了吗？”

聊天继续使用原会话的 AI。写说说、回评论的 AI 可以在本插件中单独选择，留空时跟随聊天；看照片沿用 AstrBot 的“图片转述模型”设置，留空时按系统规则使用当前会话中可看图的模型或已设置的备用模型。人格沿用 AstrBot 的聊天设置，参考照沿用生图插件，记忆沿用原来的共享范围，时间沿用 AstrBot 的全局时区。

聊天和 QQ空间始终使用同一个人格。在 AstrBot 的聊天人格设置中切换后，QQ空间会自动跟随，后续说说与回评使用当前人格和记忆范围，无需再到 QQ空间里选一次。日程插件使用的人格也需要与当前聊天一致。

切换人格时，旧人格尚未发布的自主计划会停止；旧日程尚未更新，或切换前的日程仍在生成时，会先等待当前角色的新日程。仅换穿搭不会把旧日程归给新角色。已经发出的说说、记忆和操作记录保留原归属；管理员仍可自然地要求删除同一 QQ 账号的历史说说，删除经历记回原帖所属人格。

## 设置页的五项选择

打开 **AstrBot 后台 → 插件 → QQ空间 → 配置**：

| 选项 | 默认 | 你可以决定什么 |
| --- | --- | --- |
| 自己分享日常 | 开启 | 是否让角色跟着日程拍自拍、发空间 |
| 每天最多自己发几条 | 2 条 | 用一个滑块选择每天的上限，范围 0—5 条；选 0 时暂停自主分享，手动发布和回复留言照常 |
| 回复我的留言 | 开启 | 是否自动回应你在角色空间里的新评论 |
| 写说说、回评论的 AI | 跟随聊天 | 可单独选择已有模型；看照片继续沿用 AstrBot 的识图设置 |
| 自拍没拍好时 | 稍后重试 | 选择“直接跳过”或“稍后重试”，无需填写重试次数和等待时间 |

选了最多 3 条，角色会按日程安排 1—3 条；没有合适的日常或照片时，可以少发或不发。选 0 会暂停自主分享。你主动让角色发的说说另算，删除说说也不会返还当天已用次数。

发帖时间直接取日程里明确的活动区间，夜间、跨午夜或正在进行的活动也会检查。睡眠、没有日程的空白时段，以及结束边界无法确定的活动会跳过，无需再填写一套开始、结束时间。

发布后给自己点赞默认开启。重试次数、等待时间、检查留言的频率等由插件管理，不在设置页重复展示。旧版技术参数会停止生效。升级时先保留原配置文件的原字节备份，再迁移到这五项选择；旧版每日上限与文字模型选择会保留。

AstrBot 弹窗顶部的“日志级别”是它的通用选项，保持“跟随全局”即可。

## 平时直接和角色说话

| 想做什么 | 可以这样说 |
| --- | --- |
| 引用照片，让角色配文发布 | “把这张照片发到你的空间，文案你自己写” |
| 使用自己写的文案 | “把这张图发空间，文案就写：今天的阳光很好” |
| 看最近的说说 | “让我看看你最近发了什么” |
| 删除指定说说 | “把刚才那条删掉”或“删掉喝咖啡那条” |
| 从几条相似内容中选择 | 角色给出时间和内容后，说“选第一条” |
| 查询结果 | “刚才那条说说发出去了吗？” |
| 重试确定失败的发布 | “把刚才没发成功的那张再发一次” |
| 暂停或恢复 | “先暂停自己发空间和回复评论”或“继续分享日常吧” |

操作结果交回原聊天会话，由角色结合人设、关系、上下文和记忆自行回应。技术编号和原始错误留在后台。

自动生成的说说配文是一句连贯的完整话，保留角色语气；聊天继续保持原有节奏，你明确指定的文案按原文发布。生成结果出现多句或换行时，会让模型重新写一次，仍不合适就暂不发布。

目标有多条时，角色会按时间、内容或先后顺序向你确认。发布后会给自己点赞；发布、管理员留言、角色回评和删帖都会同步记忆。

空间操作只接受 AstrBot 中已经设置的管理员账号，自动回复也只针对这些账号的新留言。其他人的留言和机器人自己的评论会略过。管理员名单直接沿用 AstrBot，QQ空间没有另一份名单让你重复填写。

## 没发成时会怎样

自主分享失败时在后台安静处理。“直接跳过”会略过这次失败的机会；“稍后重试”会在首次失败后约 10 分钟、30 分钟各再试一次。图片、识图结果和文案会保留复用；重试用完、日程过期或活动改变后，就略过这次机会，保持带图分享，当天可以一条也不发，也不会主动发消息报告错误。

你主动要求的操作会在当前聊天里得到角色反馈。暂停后，手动要求发布仍然可用；自主分享、自动回评和待补自赞暂停，已经发生的事继续补写记忆。

发送结果暂时无法确认时，会先保留原请求并阻止重复发布。可以直接说“查一下刚才发空间的结果”。实际看过空间后，再告诉角色“我确认刚才那条已经发出去了”或“我确认刚才那条确实没发出去”，随后决定是否重试。

空间已经发出而记忆插件暂时不可用时，只会补写记忆，不会重新发说说。删帖后仍保留“曾发布、后来删除”的历史，评论和回复也会标明帖子已删除。

## 依赖与已知范围

需要 **AstrBot 4.26.8 至 5.0 之前的版本**，通过 `aiocqhttp` 连接 QQ / OneBot，可使用 NapCat。登录凭据从现有 QQ 连接获取，无需手工填写 Cookie。

| 插件 | 用途 | 本次对照的源码版本 |
| --- | --- | --- |
| [LivingMemory](https://github.com/lxfight-s-Astrbot-Plugins/astrbot_plugin_livingmemory) | 保存和召回空间经历 | `2.7.1` |
| [Life Scheduler](https://github.com/muyouzhi6/astrbot_plugin_life_scheduler) | 提供穿搭和日程 | `v2.8.0` |
| [Gitee AI Image](https://github.com/muyouzhi6/astrbot_plugin_gitee_aiimg) | 按角色参考形象生成自拍 | `v5.7.5` |

- 只操作机器人自己的图片说说，暂不支持视频或好友空间批量互动。
- 启用前的旧评论不会补回；默认检查最近 20 条自己的说说，尚未连续翻取全部历史帖子或所有评论页。
- 日程缺失时会等待日程插件提供，不自行创造活动；参考照、生图服务和记忆共享方式都在原插件中维护。
- 首次接入请确认日程与参考照属于当前角色。日程插件未记录缓存生成时的人格，QQ空间会保护启用后观测到的人格切换；参考形象继续在生图插件中选择。
- 依赖插件升级后，自拍和记忆接口可能需要同步适配；其他版本组合需要另行验证。
- `v0.1.1` 已在 AstrBot `4.29.0`、NapCat `4.18.19` 完成真实 QQ 主流程实测。
- 本版通过 288 项测试及独立交叉审查，补充验证了手机照片方向、异常响应、跨午夜日程、人格切换中的日程缓存、重试核对和原记忆归属。五项设置已在真实后台验证保存与重载，自然语言查询、缺图追问、单句配文和真实日程区间也已验收；自然定时与跨天运行仍需连续观察。

## 更新与回退

更新前保留当前插件、配置和数据备份。数据通常在 AstrBot 的 `data/plugin_data/astrbot_plugin_qzone_life/`，包括发布记录、任务状态和图片缓存。

回退时先停用插件，再恢复配套的源码、配置和数据备份，随后重载。保留状态数据库，以继续识别已经发生的操作；已写进 LivingMemory 的真实记忆继续由它管理。
